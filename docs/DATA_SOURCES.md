# 数据来源与展示规则

核对日期：2026-10-13。使用 ESPN 公开网站接口，无账户或 API Key；公开访问不等于长期稳定性保证或任意再分发授权。没有自动付费或备用数据源。

| 功能 | 接口 |
| --- | --- |
| 球队 | `https://site.api.espn.com/apis/site/v2/sports/basketball/nba/teams` |
| 日期赛程、比分、状态 | 同一基础路径 `/scoreboard?dates=YYYYMMDD&limit=100` |
| 球队赛程 | 同一路径 `/teams/{id}/schedule?season={year}&seasontype={1,2,3}` |
| 详情、统计、场馆、逐次比分 | 同一路径 `/summary?event={id}` |
| 球员赛季统计（全量分页） | `https://site.web.api.espn.com/apis/common/v3/sports/basketball/nba/statistics/byathlete?season={year}&seasontype={2,3}&limit=100&page={page}&sort=offensive.avgPoints:desc` |
| 球员最近出场 | 同一 common/v3 路径 `/athletes/{id}/gamelog?season={year}&seasontype={2,3}` |
| 常规赛排名 | `https://site.web.api.espn.com/apis/v2/sports/basketball/nba/standings?season={year}&seasontype=2` |

非 NBA 球队可能没有本地队标，使用名称／简称后备，不借用其他球队标识。

## 时间与缓存

开赛瞬间转换为设备时区。日期查询覆盖相邻来源日期，再按当地日期过滤去重。更新时间是获取时间，不保证与现场同步。失败保留真实缓存并提示，首次无数据呈现空状态。前台比赛适度刷新，后台停止轮询，可手动刷新。

不同接口可能有快照时间差，总分、分节、球员表与逐次比分可能暂未同步，不擅自改写来源数值强行对齐。

## 统计

按 ESPN ID 匹配中文，保留英文原名；未知球员保留英文。每队独立计算各列最大值，并列均标记，未上场和缺失值排除，全零列不制造高亮。投篮类分别比较命中和出手，时间按秒比较；正负值按有符号数比较，例如 −2 高于 −7。失误和犯规的高亮不表示表现更好。

普通统计数值使用中性色，最高值统一蓝色。比分只在进行中或已结束且两侧数值有效时判断领先；平分、未开始或缺失比分不虚构领先方。曲线与对比细条使用主队蓝色、客队橙色，颜色不替代队名、数值与状态文字。

在场仅使用实时响应的 `active` 字段，首发不能替代。在数据超过 90 秒、失败或比赛结束后取消红色提示。

## 曲线与降级

按有效逐次记录的累计比分、节次与时间绘制阶梯曲线。常规每节 12 分钟，加时每节 5 分钟。缺少开场记录或终点不一致时提示不完整，不虚构 0:0 或终点。双队颜色配合实／虚线，长按拖动读取已获取记录。

无法从采样记录保证中间所有事件完整，不承诺实时准确性或请求速率。网络、限流或结构变化时展示带获取时间的缓存；缺少统计、场馆、曲线分别显示明确状态。接口测试成功不代表所有中国手机网络都可稳定访问。

## 联盟球员统计与分页

`season` 使用赛季结束年份，例如 2026 为 2025–26。2026-10-13 实测常规赛共 578 人、六页、578 个不同 ID；季后赛接口也可访问。当前 2026–27 常规赛尚未开始，接口仅返回当前赛季资料，展示空状态并提供上一赛季入口。未来不可用、限流或改变结构时，不承诺继续覆盖。

应用核对每页请求赛季、阶段、页码与总数，最多并行三页。所有页完整、数量一致且没有重复 ID 才更新汇总缓存。分页失败保留上次完整缓存，首次失败不将局部列表称为全量名单。统计缓存三小时，手动刷新绕过有效期，不后台持续轮询。只使用 HTTPS，自己构造页码，不能跟随来源返回的 HTTP 链接。

场均与总计来自同一来源字段；总计不由四舍五入后的场均相乘。转会球员来源合并行显示多队，球队筛选匹配其中任一球队，数值始终为整个赛季合计，避免误称为该队期间数据。百分比按实际命中和出手计算，零出手显示破折号。联盟源没有提供正负值等字段，不能为联盟列表生成假数据；单场正负值继续使用比赛详情。

榜单包含少量出场球员，可按场次、场均时间过滤；这些是自定义筛选，不能称为官方榜单资格。最高值按当前筛选范围比较，并列均标记。球员记录接口会同时返回常规赛与季后赛，应用主动隔离所选阶段，按真实开赛瞬间排序，只取最近五次出场记录。

中文名以收录资料为限；全联盟历史赛季中尚有未收录球员，保留准确英文原名，不承诺历史名单全部中文化。
