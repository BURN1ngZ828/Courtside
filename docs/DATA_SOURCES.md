# 数据来源与展示规则

核对日期：2026-10-13。使用 ESPN 公开网站接口，无账户或 API Key；公开访问不等于长期稳定性保证或任意再分发授权。没有自动付费或备用数据源。

| 功能 | 接口 |
| --- | --- |
| 球队 | `https://site.api.espn.com/apis/site/v2/sports/basketball/nba/teams` |
| 日期赛程、比分、状态 | 同一基础路径 `/scoreboard?dates=YYYYMMDD&limit=100` |
| 球队赛程 | 同一路径 `/teams/{id}/schedule?season={year}&seasontype={1,2,3}` |
| 详情、统计、场馆、逐次比分 | 同一路径 `/summary?event={id}` |
| 常规赛排名 | `https://site.web.api.espn.com/apis/v2/sports/basketball/nba/standings?season={year}&seasontype=2` |

非 NBA 球队可能没有本地队标，使用名称／简称后备，不借用其他球队标识。

## 时间与缓存

开赛瞬间转换为设备时区。日期查询覆盖相邻来源日期，再按当地日期过滤去重。更新时间是获取时间，不保证与现场同步。失败保留真实缓存并提示，首次无数据呈现空状态。前台比赛适度刷新，后台停止轮询，可手动刷新。

不同接口可能有快照时间差，总分、分节、球员表与逐次比分可能暂未同步，不擅自改写来源数值强行对齐。

## 统计

按 ESPN ID 匹配中文，保留英文原名；未知球员保留英文。每队独立计算各列最大值，并列均标记，未上场和缺失值排除，全零列不制造高亮。投篮类分别比较命中和出手，时间按秒比较；正负值按有符号数比较，例如 −2 高于 −7。失误和犯规的高亮不表示表现更好。

在场仅使用实时响应的 `active` 字段，首发不能替代。在数据超过 90 秒、失败或比赛结束后取消红色提示。

## 曲线与降级

按有效逐次记录的累计比分、节次与时间绘制阶梯曲线。常规每节 12 分钟，加时每节 5 分钟。缺少开场记录或终点不一致时提示不完整，不虚构 0:0 或终点。双队颜色配合实／虚线，长按拖动读取已获取记录。

无法从采样记录保证中间所有事件完整，不承诺实时准确性或请求速率。网络、限流或结构变化时展示带获取时间的缓存；缺少统计、场馆、曲线分别显示明确状态。接口测试成功不代表所有中国手机网络都可稳定访问。
